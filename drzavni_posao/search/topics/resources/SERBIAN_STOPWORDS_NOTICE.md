# Serbian Stop Word Dictionary

`serbian_stopwords_ssw.csv` is derived without textual changes from
[UlfetaMarovac/stopwordsSerbian](https://github.com/UlfetaMarovac/stopwordsSerbian)
at commit `74ed3400321aadc029b6f49be8b10b829132edf7`.

The dictionary was created by Ulfeta Marovac, Almir Avdić, and Azra Ljajić and
contains Serbian auxiliary verbs, pronouns, adverbs, prepositions,
conjunctions, exclamations, particles, and abbreviations.
